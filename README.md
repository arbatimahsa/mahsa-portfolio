# Mahsa Arbati — Personal Portfolio

A responsive personal portfolio website for **Mahsa Arbati**, a Computer Science graduate and Associate Product Manager focused on AI systems, product innovation, workflow automation, RAG, and multi-agent systems.

## Live Demo

After enabling GitHub Pages, the portfolio will be available at one of these URLs:

- `https://arbatimahsa.github.io/` if the repository is named `arbatimahsa.github.io`
- `https://arbatimahsa.github.io/mahsa-portfolio/` if the repository is named `mahsa-portfolio`

## About

This portfolio highlights Mahsa's academic background, AI/product projects, professional experience, technical skills, soft skills, certifications, and contact links. It is built as a single-page website with a clean glassmorphism-inspired design, responsive layout, dark/light mode, animated UI elements, and JavaScript-rendered project, skill, education, and certification sections.
